# Demo: Slug Service

## Stack

- Language: JavaScript (ESM)
- Runtime: node

## Conventions

- Every bug fix ships with a regression test that fails before the fix and
  passes after it.
- Success is a recorded test run, not a claim.

## Quick Start

```bash
node --test
```
