# SPEC-0007: Demo Widget

## Purpose

Let a user toggle a demo widget.

## User Outcome

The user can flip the widget on and off.

## Scope

- A single toggle on the home screen.

## Non-Goals

- Persistence across sessions.

## Flow

Tap the toggle; the widget flips.

## Acceptance Criteria

- Toggling flips the widget state.

## Prompt Notes

- Requirements: a toggle on the home screen.
- Structure: one component plus a state flag.
