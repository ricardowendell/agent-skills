# Decisions

Architecture Decision Records. One file per decision,
`ADR-NNNN-short-name.md`, numbered from the highest existing file.

Each ADR covers:

- **Status** — proposed / accepted / superseded by ADR-NNNN
- **Context** — the forces at play
- **Decision** — what was chosen
- **Consequences** — what this makes easy, and what it makes hard

Record the decision and its trade-off; do not restate `docs/architecture.md`.
