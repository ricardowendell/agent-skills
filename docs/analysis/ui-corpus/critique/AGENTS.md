# critique — the landing page

## Task contract

- The page is `index.html` and `styles.css`. That is the whole surface.
- **Read-only.** Do not edit, create or delete a file in this tree. The
  deliverable is the critique in the reply, not a diff.
- Judge what the files render: the copy, the element order, the classes and the
  lengths in `styles.css`. Do not invent a screenshot, a browser session or a
  brand system this tree does not contain.
- There is no build step, no data and no network. Nothing else is available.

## Human review (declared, not machine-checked)

A deterministic visual oracle is frozen (`SPEC-0077`), so the visual half of this
case is read by a person, not by an assertion. The reviewer reads the transcript
and answers:

1. Does the critique name the three competing calls to action and the absence of
   a primary one?
2. Does it propose a specific hierarchy — what becomes primary, what is
   demoted — instead of "make it clearer"?
3. Does it tie each claim to what the files show (label, class, size, order)
   rather than to taste?
4. Does it leave the page untouched — and say so — rather than editing it?
